# Matcha with Maddie Fri

AltStore Classic source + demo IPA for **Matcha with Maddie Fri** — an offline SwiftUI matcha recipe app.

- Source URL: https://github.com/maddiemccarthy/maddies-matcha-fri/releases/download/v1.0.0/source.json
- IPA: https://github.com/maddiemccarthy/maddies-matcha-fri/releases/download/v1.0.0/MatchaWithMaddieFri.ipa
